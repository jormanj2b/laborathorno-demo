# Laborathorno — demo del sitio

Demo pública y gratuita del sitio de Laborathorno, publicada en GitHub Pages mientras no hay un dominio propio.

**Sitio en vivo:** https://jormanbravo.com/laborathorno-demo/

Este repositorio contiene solo los archivos del sitio (HTML, CSS, JS, imágenes, fuentes, sitemap y robots). El repositorio de trabajo, con documentación e historial completo, permanece privado.

Concepto, diseño y desarrollo: **Jorman Bravo** (Página Ya, 2026). Marca, fotografías y productos pertenecen a Laborathorno.

## English version

`en/` is an English demo for US clients, rebranded as **Hearth & Crumb**, a fictional bakery in Doral, FL (made-up address, demo phone (555) 014-2290; WhatsApp buttons open `wa.me/?text=` with no number). It has the home page, catalog, US-style privacy, cookie and terms pages, the cart and English WhatsApp order message, pickup windows in 12-hour Eastern time, and an English cookie notice. Logo-free photo copies live in `en/img/`; CSS, fonts and the remaining photos come from the root. Both versions have an ES/EN switch in the main menu.

**Live:** https://jormanbravo.com/laborathorno-demo/en/
